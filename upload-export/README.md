# Upload / Export

**Open it:** press the orange **Upload** button in the top bar on any page (or **Export** in the editor). A window opens with two steps.

## Every button

### 1 · Upload

- **3D model** (left) — your skin, turning slowly. On phones it is hidden.
- **Upload another file / Drop your skin or image here** — the big button: click to choose a file, or drop one anywhere on the dashed box. PNG, JPG, WEBP, BMP or GIF; skins 64 to 512 px are detected, old 64×32 skins open in the 64×64 layout, any other picture becomes a skin texture.
- **or paste with Ctrl + V** — paste a picture you copied.
- **Skin name** — also the file name when you download.
- **Size · colours · swatches** — the skin's size and how many colours it uses, most used first.
- **Skin size** — 64×64 (Java + Bedrock), 128×128 (HD, Bedrock), 256 or 512 (HD). Changing it can be undone in the editor.
- **Arms: Steve / Alex** — classic 4 px or slim 3 px arms.
- **Continue in: Editor / Repair / Pose** — closes the window and opens that tool with this skin.

### 2 · Export

- **Minecraft edition: Java Edition / Bedrock Edition** — Java gets a PNG at 64×64 (the only size its launcher accepts), Bedrock gets a .mcpack skin pack (up to 128×128).
- **File name** — the name of the download; the ending (.png / .zip / .mcpack) is shown next to it.
- **Include my cape / elytra** — only when you made a cape: Java gets a .zip with the skin and cape, Bedrock puts the cape inside the .mcpack.
- **What do you want to do?** — **Public** (in the skin gallery for everyone), **Private** (saved to My skins, only you) or **Only download**.
- **Execute** — the big button: **Download for Java / Bedrock**, **Publish to gallery** or **Save to My skins**. Public and Private need a free account; if you are logged out it asks you to log in and then continues where you were.
- **More** (in the 2 · Export title bar) — **GIF / video**, **Cape PNG**, **Moving cape**, **Cape picture**, **JSON**, **PNG only** (Bedrock), **Skin pack** (several skins in one .mcpack) and **Share link** (a link that opens a copy of your skin in the editor).
- **✕ / Esc / clicking outside** — closes the window.

## Image to Minecraft skin: upload any picture or skin PNG

Upload a skin file or any picture (PNG, JPG, WEBP, BMP, GIF). The size is detected for you; pick Java or Bedrock, the size, Steve or Alex and a name, then open it in the editor.

*On the website, with screenshots: https://mc-engine.app/docs/upload-image*

### Step 1 · Drop your file

Press **Upload** in the top bar — the **Upload / Export** window opens on any page. In **1 · Upload**, press the big **Upload** button to choose a file, drop a file on the box, or paste a picture with **Ctrl + V**.

Minecraft skins (64, 128, 256 or 512 pixels) load as they are, and old 64×32 skins open in the 64×64 layout. Any other picture is turned into a skin texture. Your skin turns in 3D on the left.

1. **Drop zone**: PNG, JPG, WEBP, BMP, GIF.
2. **Detected**: what the file is, e.g. "Minecraft skin 64×64".

### Step 2 · Check the skin settings

**Skin name**: used as the file name when you download. Next to the picture you see the **size** and how many **colours** the skin uses.

**Skin size**: 64×64 up to 512×512 — set from your file, and you can change it. **Arms**: Steve (4 px) or Alex (3 px).

Java or Bedrock is picked in **2 · Export**. An HD skin (128 or bigger) picks Bedrock for you, because Java's launcher only takes 64×64.

1. **Skin name**, size and colours.
2. **Skin size** and **Arms**.

### Step 3 · Open it in the editor

Under **Continue in**, press **Editor** to keep painting, **Repair** if the faces of a picture landed in the wrong places, or **Pose** to pose it and take pictures. The window closes and that tool opens.

1. **Editor** · **Repair** · **Pose**.


## How to put a custom skin in Minecraft Java & Bedrock

Choose Java or Bedrock in the Upload / Export window and download: a PNG for the Java launcher, or a .mcpack that Bedrock imports on phone, tablet and Windows.

*On the website, with screenshots: https://mc-engine.app/docs/use-in-minecraft*

### Step 1 · Pick Java or Bedrock and download

Press **Upload** in the top bar (or **Export** in the editor) to open the **Upload / Export** window. In **2 · Export**, pick **Java Edition** or **Bedrock Edition**, check the **file name**, keep **Only download** chosen and press **Download**.

Java gets a **PNG** saved at 64×64 — the only size the Java launcher accepts, even if you painted in HD. Bedrock gets a **.mcpack** skin pack (up to 128×128).

1. **Java Edition** or **Bedrock Edition**.
2. **File name**.
3. **Download**.

### Step 2 · Java Edition

Open the **Minecraft Launcher** → **Skins** tab → **New skin**.

Pick the PNG you downloaded, choose **Classic** (Steve) or **Slim** (Alex) — the same arms you picked on the site — and press **Save**. The page shows these steps under the Download button.

1. **The 3 steps** for the edition you picked.

### Step 3 · Bedrock (phone, tablet, Windows)

Open the downloaded **.mcpack** file — Minecraft opens and imports it.

Then in Minecraft go to **Dressing Room → Classic skins** and pick your pack and skin.

### Step 4 · More options

When you made a cape, **Include my cape** (above the download button) adds it: Java gives a **.zip** with the skin and the cape PNG (plus the moving GIF for a moving cape), Bedrock puts the cape inside the **.mcpack** (64×32).

**More** (in the **2 · Export** title bar) has **GIF / video** (a walking, turning clip to share), **Cape PNG**, **Moving cape** and **Cape picture** (your skin from behind wearing the cape — when you made one), **JSON** (every pixel and its colour, for other tools), **Skin pack** and **Share link**. With Bedrock picked there's also **PNG only**. To put the skin in the gallery, choose **Public** (or **Private** for only you) instead of **Only download**.

**Skin pack** puts several skins into one Bedrock **.mcpack**: add the current skin, PNG files, Drafts or your saved skins, give each a name and Steve / Alex arms, order them, name the pack and download. In Minecraft they all show under Dressing Room → Classic skins → your pack.

**Share link** (in the Upload / Export window) makes a short link that opens a copy of your skin straight in the MC-ENGINE editor — nothing is posted to the gallery. The link is copied for you; make a new one after you change the skin.

1. **Include my cape**: Java .zip / inside the Bedrock .mcpack.
2. **More**: GIF / video · Cape PNG · Moving cape · Cape picture · JSON · Skin pack · Share link.
